# MOBILY BRO+ — منصة شحن الألعاب والتطبيقات

منصة بيع وتشغيل ذاتي لخدمات الشحن الرقمي (الألعاب، التطبيقات، بطاقات الهدايا، الرصيد) — دفع عبر **شام كاش** — بإدارة **أيمن زيدان**.

## البنية التقنية
- **الواجهة:** React 18 + Vite + Tailwind (هوية بنفسجية/ذهبية، خط Cairo، عربي RTL) — تطبيق ويب تقدمي PWA قابل للتثبيت
- **الخلفية:** دوال Serverless على Vercel (`/api/*`)
- **قاعدة البيانات:** Supabase Postgres (منتجات، طلبات، إعدادات، سجلات)
- **مزود الجملة:** Market-Card API (`app.market-card99.com/api/v2`)

## دورة الطلب
1. الزبون يختار منتجاً ويدخل رقم حسابه ويرسل الطلب ← يحصل على رقم طلب `MB-XXXXXX` ومبلغ دقيق
2. يحوّل المبلغ عبر شام كاش إلى المحفظة المعرّفة
3. الإدارة تؤكد استلام المبلغ بضغطة من لوحة التحكم
4. النظام يرسل الطلب آلياً إلى Market-Card ويُتابع حالته حتى `success/cancel`
5. الزبون يرى النتيجة حياً في صفحة الطلب (تحديث تلقائي كل 6 ثوانٍ)

## المتجر (واجهة الزبون)
| المسار | الوصف |
|---|---|
| `/` | الرئيسية: أقسام + الأكثر طلباً + تتبع سريع |
| `/categories` و `/c/:id` | الأقسام والفئات مع فلترة |
| `/p/:id` | صفحة المنتج وإنشاء الطلب |
| `/pay/:code` | تعليمات الدفع + تتبع حي |
| `/track` | تتبع طلب برقمه |

## لوحة الإدارة `/admin`
- **الطلبات:** فلترة بالحالة، بحث، تأكيد دفع (يتطلب تأكيد ثانٍ)، فحص الحالة لدى المزود، إعادة محاولة، إلغاء، تأشير إرجاع
- **المنتجات:** مزامنة كاملة من Market-Card (أقسام + أسعار جملة)، إخفاء/إظهار، أسعار بيع محسوبة آلياً (سعر الدولار + هامش الربح)
- **الإعدادات:** رقم محفظة شام كاش، سعر الدولار، الهامش، بيانات حساب Market-Card، كلمة سر الشراء، وضع Demo، كلمة مرور اللوحة
- **الرصيد:** رصيدك وسجل الحركات لدى Market-Card

## الإطلاق الحقيقي (خطوتان من الإعدادات)
1. أدخل بيانات حسابك في Market-Card (اسم المستخدم + كلمة المرور) وأطفئ "وضع العرض التجريبي"
2. اضغط "مزامنة المنتجات" — يُستورد كل الكتالوج ويُحسب سعرك تلقائياً

## الأوامر
```bash
npm run dev        # تطوير محلي
npm run build      # بناء الإنتاج
npm run sql -- supabase/sql/01_schema.sql   # تطبيق SQL على Supabase
npm run icons      # توليد أيقونات PWA
```
